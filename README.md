# YAVC 2.0 - Video compressor

This program implements a video encoder and decoder algorithm based on multiple modules like quadtrees, dct and block motion estimation using hexagon search and exaustive search.
A similar processing workflow that can be found in the industry standard H.264 codec was used.

# Deprecation Warning

The YAVC-2 compressor is a deprecated codec of the YAVC collection. A newer, more performant version with a better compression ratio is currently in development.
